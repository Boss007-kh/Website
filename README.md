# Preety Cake Factory

A responsive, accessible starter website for a cake business.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will give you a `github.io` address.

## Customize
Search `styles.css` for colors and `index.html` for:
- cake names
- prices
- WhatsApp number
- opening hours
- About text
- testimonials
- image URLs

The current phone number and address-style information are placeholders.
